## 단계 ①~④: 한 일과 근거

### ① 원본 읽기와 날짜 변환

- 한 일: 원본을 읽고 날짜 세 열을 날짜형으로 변환했습니다.
- 처리 전 → 후: 1,030행 × 14열 → 1,030행 × 14열.
- 근거: 날짜 순서와 배송 기간을 계산하기 위해 변환했습니다.

### ② 중복 행 제거

- 한 일: 완전히 같은 행 26건을 제거했습니다.
- 처리 전 → 후: 1,030행 → 1,004행.
- 근거: 중복 행은 금액을 포함한 모든 열이 같아 한 번만 집계했습니다.

### ③ 수량 복원

- 한 일: 수량이 100을 넘는 22건을 `총액 ÷ 단가`로 복원했습니다.
- 처리 전 → 후: 최대 수량 990, 총액 불일치 22건 → 최대 수량 99, 총액 불일치 0건.
- 근거: 나눈 값이 정수인 것을 확인하고 수량 오기입을 복원했습니다.

### ④ 날짜 오류 표시와 저장

- 한 일: `date_error`를 추가하고 `sales_clean.csv`를 저장했습니다.
- 처리 전 → 후: 1,004행 × 14열 → 1,004행 × 15열, `date_error=True` 147건.
- 근거: 도착일이 배송일보다 앞선 행은 실제 날짜를 알 수 없어 수정하지 않고 표시했습니다.

고객 나이 51건, 만족도 30건, 도착일 5건의 결측치는 근거 없이 값을 만들어 넣지 않기 위해 그대로 유지했습니다.

## 단계 ⑤~⑦: 답

### ⑤ 배송 기간은 보통 며칠인가?

날짜 순서가 맞고 기간을 계산할 수 있는 852건의 평균은 22.05일, 중앙값은 2일입니다.  
364~370일인 47건이 평균을 크게 올리므로, 원본과 저장 CSV는 유지하고 보통 기간 계산에서만 제외했습니다. 그때 평균은 1.93일, 중앙값은 2일입니다.

### ⑥ 만족도가 낮을수록 반품이 많은가?

아닙니다. 만족도 1~5점의 반품 비율은 각각 7.59%, 11.96%, 7.81%, 8.72%, 6.93%로 일정하게 변하지 않습니다.  
가장 높은 비율은 2점의 11.96%이고 5점은 6.93%입니다. 만족도 결측 30건은 이 비교에서 제외했습니다.

### ⑦ 카테고리 매출 1위의 이유는 무엇인가?

매출 1위는 가구 28.43억 원이며 2위는 식품 25.13억 원입니다.  
가구와 식품의 건수는 213 대 210, 평균 단가는 257,323원 대 255,233원, 평균 수량은 51.04개 대 47.31개로 세 지표 중 평균 수량 차이가 가장 큽니다.
